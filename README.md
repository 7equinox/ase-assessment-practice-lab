# ASE Assessment Practice Lab
**Practice. Understand. Improve.**

An open-source preparation laboratory designed for candidates seeking Associate Software Engineer (ASE) recruitment assessment readiness at Accenture Philippines.

---

### Disclaimer
*Independent learning tool. Not affiliated with, endorsed by, or officially provided by Accenture. Practice questions are original and are not guaranteed to appear in any actual recruitment assessment.*

---

### Architectural Highlights
- **100% Client-Side & Free Deployment:** Built with React 18, TypeScript, and Vite. Compliant with GitHub Pages static hosting. Requires no Node.js backend, no SQL database, and no runtime external API keys.
- **Continuous Question Generation:** Uses parameterized templates and mathematical/logical state machines to generate unlimited problem variations across four distinct assessment parts.
- **Accurate Reference Grounding:** Explanations cite verified educational resources including LearnCpp, CppReference, Purdue OWL, and standard competency frameworks.
- **Device Responsiveness:** Fully responsive interface tested from 360px mobile viewports to desktop resolutions.

---

### Assessment Parts Covered
1. **Cognitive and Logical Reasoning:** Abstract sequences, numerical differences, formal deductive syllogisms, cartesian vector map navigation, and an interactive logic experiment sandbox.
2. **C++ Programming Fundamentals:** C++17 execution tracing, memory pointers (`*` and `&`), function pass-by-reference, OOP virtual polymorphism, and loop tracing.
3. **Behavioral Assessment & Learning Agility:** Situational judgment tests grounded in organizational competencies (blameless root-cause analysis, learning agility, code reviews, and ownership).
4. **English Proficiency:** Subject-verb agreement, correlative conjunctions, tense sequences, technical context vocabulary, and passage-grounded reading comprehension.
